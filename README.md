# サイネージセレクター

I-O DATA製の大型ディスプレイ・壁掛け金具／イーゼルスタンド・再生機・再生アプリを、
「映す・再生させる・取り付ける」のセットでまとめて選べるツールです。
NAS／ISS／DAS／スイッチセレクターと同じ仕組み（GitHub Pages＋毎日の自動データ更新）で動きます。

- 公開URL（Pages有効化後）：https://ioplaza02.github.io/signage-selector/
- パスワード：`app.js` の `SITE_PASSWORD`（初期値 `signage2026`）※簡易的な鍵です

## 構成

```
index.html / style.css / app.js   画面（メイン・やりたいことで選ぶ・ディスプレイウォール）
data/displays.json                 ディスプレイと金具の対応（自動更新）
data/static.json                   金具の寸法・再生方式・やりたいこと表・リンク（手で管理）
images/tool.png                    金具カードの工具アイコン（任意。無ければ表示しない）
scripts/scrape.mjs                 公式サイトからデータを集める
scripts/health-check.mjs           取得結果の健全性チェック
scripts/make-sample.mjs            動作確認用サンプルデータを作る
.github/workflows/scrape.yml       毎日 深夜3:00（日本時間）の自動実行
```

## データの集め方

1. 液晶ディスプレイオプション（スタンド／金具）対応表から、40型以上のディスプレイと
   DA-WM2 / DA-WML2 / DA-ES1 の対応（○△▲×・ネジ・注記・縦設置時の電源ボタン位置）を読む
   - 注記（※1など）の番号はサイズ区分ごとに意味が違うため、取得時に文章へ置き換えて保存
   - 表のセルの縦結合（rowspan）を展開してから読むので、型番セルと記号・ネジの行がずれない
2. 各ディスプレイの商品ページ（足りなければ spec.htm）から、外形寸法・質量・連続稼働時間・
   防塵・内蔵プレーヤー・ディスプレイウォール・傾け可否・販売状況を読む
3. `data/displays.json` に保存

リクエストは1件ずつ2秒間隔、専用User-Agent（SignageSelectorBot/1.0）。

## 手動でデータを更新する

```
node scripts/scrape.mjs
```

最後に機種ごとの取得結果と「取れなかった項目」が表示されます。

## 自動更新

毎日 深夜3:00（日本時間）に実行。健全性チェック（機種数が1割以上減っていないか／
寸法・質量が3割以上の機種で空になっていないか／金具の対応が半数以上空でないか）に
問題が無ければそのまま反映し、異常時は反映せずPRとIssueを作って知らせます。
